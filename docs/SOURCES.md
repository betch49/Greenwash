# Greenwash Radar — External sources (v1.1)

Written by the director on 2026-10-21 for the v1.1 plan (PLAN.md Phases 10–15). One row per source the orchestrator's research put forward, with what the director observed from the build container, the licence or access terms as read, and the ruling: **scored signal**, **ground truth only** (evaluation, never an input to the score), **methodology support only**, **LATER**, or **rejected**. Decisions are logged as ADRs in `docs/DECISIONS.md` (ADR-025 to ADR-031).

Two rules bind every row:

1. **Ground-truth labels never feed the score.** A source marked "ground truth only" is read by the validation harness (Phase 10) and by nothing under `src/`. A test pins this (criterion 10.4).
2. **A scored source needs a receipt.** URL, fetch date and excerpt, exactly like every v1 signal (`assertReceipt`). A source whose data cannot be fetched from the pipeline with a stable URL cannot be scored, however credible it is.

## Validation ground truth: how an entry is made (binding for Phase 10)

`fixtures/validation/ground-truth.json`, schema in `src/lib/validation/ground-truth.ts` (the only module under `src/` that may read it, and it is imported by `scripts/validate.ts` and tests only — criterion 10.4):

```
{ "version": 1, "label_use": "evaluation_only",
  "entries": [ { "slug", "name", "wikidata_id"?, "website", "group": "flagged" | "well_rated" | "contested",
                 "citations": [ { "source": "<register key>", "url", "date": "YYYY-MM-DD", "why": "<one line>",
                                  "verified_from_container": true|false } ] } ] }
```

- **flagged** (target 20, minimum 15): at least one citation from a credible third party in the register above (greenwash.com brand page; CCRM 2025 low/very low integrity; ASA or JDP upheld ruling on an environmental claim; a Sabin case whose summary concerns a green claim; SBTi "Commitment Removed" with `status_reason` other than "Target set at parent company level" or "Company change"). Candidates seen reachable today: the greenwash.com brand index (113 pages), the recorded ASA rulings (Oatly, Shell search), the recorded JDP decisions (TotalEnergies), and the 1,500 near-term "Commitment Removed" rows. The builder picks brands that Wikidata resolves to a company with a website (Phase 1 rule) and whose site is reachable, and records every citation by fetching it.
- **well_rated** (target 20, minimum 15): **no** flagged citation found after checking every flagged source above, **and** at least two positive markers from: SBTi "Validated Targets" on both near-term and net-zero; CCRM 2025 "reasonable" or "moderate" integrity; Fashion Transparency Index top decile; Net Zero Tracker target with interim targets and published plan; B Corp. This is a weak label by construction ("no credible flag found", not "proven honest") and `docs/METHODOLOGY.md` must say so.
- **contested**: a brand with both a flag and strong positive markers. Listed, excluded from the separation statistic, reported separately.
- Every citation has `url`, `date` and `why`; `verified_from_container: false` is allowed only for NewClimate and B Corp.
- Labels are evaluation-only. No module under `src/lib/pipeline`, `src/lib/score` or any adapter imports the file or its schema; `npm run validate` is the only consumer besides tests.
