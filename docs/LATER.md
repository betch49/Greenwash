- **Quotation and stance detection for the claim engine.** Sentences that quote a third party, criticise a practice or state a global statistic can match a claim rule (seen on Oatly, Mammut, Fairphone pages). v1 shows every match with its sentence (ADR-015); a deterministic quote/stance filter is a later improvement.
- **Receipted absence kinds for the evidence and repair axes (ADR-020, CHALLENGES C-4).** Today `evidence.absolute_emissions_found` and `evidence.supplier_list_found` carry 0 points and have no risk counterpart, so a brand that publishes neither scores the same as one that publishes both; likewise a brand whose only repair information is community-written (iFixit) scores like one with its own manual. Emit `evidence.no_absolute_emissions_found`, `evidence.no_supplier_list_found` and `repair.no_brand_repair_info_found` (receipt = the scanned pages, as `no_report_found` does today) with points in `config/weights.json`, then re-pin the fixture scores. Keeps every point ≥ 0, so criterion 6.2 still holds. (Director, Phase 6 review.)
- **Recorded (not hand-authored) LLM fixtures and an LLM answer cache.** Phase 7's `fixtures/llm/` files are stand-ins because no API key was available; with a key, re-record them with `GR_OFFLINE_FIXTURES=1 GR_RECORD_LLM=1`. Caching real LLM answers in SQLite (keyed like the fixtures) would make re-runs free and reproducible. (Builder, Phase 7.)
